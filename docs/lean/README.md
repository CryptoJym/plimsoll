# Lean Plimsoll contract documents (round 12 = B0 round 6, eco-6hoxj.164.4)

The contract documents of the lean-Plimsoll program (round 12 = B0 round 6, after the independent read of C1 that followed
round 11), carried in this repository so the pending contract tests under `tests/contracts/lean/` can cite and read them by
repository-relative path. `CONTRACTS.md` is normative for the B0 items (C1-C8); `FREEZE.md` says what the lead has signed and what is
ready for signature; `CHANGES.md` maps every review item to its section, fixture and test; `SUMMARY-FOR-JAMES.md` is the
plain-language summary of this round; `DECISION-METRICS.md` the metric definitions the gates cite; the other files are the round-6
plan documents with the recorded round-7 to round-12 edits. The cloud repository's tests refer here.
