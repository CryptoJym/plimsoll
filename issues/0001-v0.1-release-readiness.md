### Walkthrough blocker note (W-2)
The fresh-Mac walkthrough could not be produced from inside the 0001 lane: the lane
host's Node-family binaries are stubbed (every invocation prints `22.0.0` and exits 0,
including `node --version`; `pnpm install` in this checkout created no node_modules),
and running the real installer would write outside the lane directory
(`~/.plimsoll`, LaunchAgents, tool configs) either way. The isolated equivalents that
DO run in CI remain the standing proof of the install→session→status→report path:
`proof:system-e2e` (+ verify/tamper variants) and `proof:signal-fidelity`. A director
must run the literal walkthrough on a clean Mac and commit the transcript to `evidence/`
(note: `evidence/` is gitignored — force-add the transcript file if it should ship).
